# опт: — Claude понимает тебя с первого раза

Хук и скилл для [Claude Code](https://claude.com/claude-code). Пишешь `опт:` и задачу, а перед выполнением отдельный агент (Sonnet) переписывает её в точный английский промпт: подставляет файлы, названия и детали из твоего проекта и переписки. Claude получает чистое, полное задание и делает его с первого раза.

```
опт: поправь цену набора L на 9500
```

Без `опт:` ты получаешь «что поправить? где? в каком файле?» и платишь за каждую попытку. С ним Claude сразу видит задачу целиком.

> English in short: type `opt: <task>` (or `опт:`) in Claude Code. A hook runs a headless Sonnet that rewrites your task into a precise English prompt using CLAUDE.md / AGENTS.md / STATUS.md and the recent conversation, and Claude executes that. Also available as `/optimize <task>`. Node.js 18+ and Claude Code required. MIT.

## Как это выглядит

Ты пишешь:

```
опт: добавь в футер ссылку на политику конфиденциальности
```

Агент видит папку проекта и заметки в `CLAUDE.md`, понимает, что у тебя Next.js и где лежит футер, и отдаёт Claude примерно такое (это пример, текст зависит от твоего проекта):

> In `src/components/Footer.tsx`, add a link to the privacy policy page (`/privacy`) next to the existing footer links, using the same styles. If the page does not exist yet, tell the user instead of creating it. Do not change anything else. Reply to the user in Russian.

Claude начинает ответ строкой «Оптимизированный запрос выполняется» и выполняет уже его. Твоя исходная формулировка остаётся рядом как справка: если смысл разошёлся, верна она.

## Установка

Нужны [Node.js](https://nodejs.org) 18+ и установленный Claude Code.

Одной командой:

```bash
npx github:tw1st3rrr/claude-skill-optimize
```

Или через клонирование:

```bash
git clone https://github.com/tw1st3rrr/claude-skill-optimize.git
cd claude-skill-optimize
node install.js
```

Потом перезапусти Claude Code. Установщик:

- кладёт хуки в `~/.claude/hooks/` и скилл в `~/.claude/skills/optimize/`;
- добавляет хук `UserPromptSubmit` в `~/.claude/settings.json`, **остальные твои настройки не трогает**;
- перед правкой делает копию `settings.json.bak-<время>`;
- безопасно запускается повторно (обновление), а при битом `settings.json` ничего не меняет и говорит об этом.

Хочешь сначала посмотреть, что будет: `node install.js --dry-run`.
Удалить: `node install.js --uninstall`.

## Как пользоваться

| Что написать | Что произойдёт |
|---|---|
| `опт: задача` | хук переписывает задачу и подмешивает результат; Claude выполняет |
| `opt: задача` | то же, для английской раскладки |
| `jgn: задача` | то же: это `опт` на английской раскладке, если забыл переключить |
| `/optimize задача` | то же, но вручную через скилл; рерайт показывается блоком перед выполнением |

Префикс считается только в **начале** сообщения. Пустая задача (`опт:`) ничего не запускает.

## Что отправляется и сколько стоит

На каждое сообщение с префиксом делается **один дополнительный запрос** к Sonnet через твой же вход в Claude Code (отдельного ключа не нужно). Он занимает 10-30 секунд и расходует твой тариф или баланс, как любой другой запрос.

В этот запрос уходит:

- текст твоей задачи, путь рабочей папки и сегодняшняя дата;
- начало файлов `CLAUDE.md`, `AGENTS.md` (по 30 строк) и `STATUS.md` (40 строк) из рабочей папки и трёх папок выше;
- последние 6 реплик текущей сессии (по 700 знаков).

Ничего не отправляется никуда, кроме Claude. Если в этих файлах лежат секреты, уберите их оттуда: агент их увидит.

Почему это окупается: русский текст занимает в токенах больше английского, а размытая задача заставляет Claude гадать и переделывать. Один короткий вызов Sonnet обычно дешевле, чем несколько попыток. Точных цифр я не обещаю: зависит от твоих задач.

## Настройка

Переменные окружения:

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `OPT_MODEL` | `sonnet` | модель рерайтера (`sonnet`, `opus`, `haiku`) |
| `OPT_TIMEOUT_MS` | `80000` | сколько ждать рерайт |
| `CLAUDE_BIN` | ищется сам | полный путь к `claude`, если установщик не нашёл |

Правила рерайта (системный промпт) лежат в `~/.claude/hooks/optimize-rewrite.js`, константа `SYSTEM`. Можно править под себя.

## Если не работает

- **Префикс ничего не делает.** Перезапусти Claude Code. Проверь, что в `~/.claude/settings.json` есть `optimize-prefix.js` в `hooks.UserPromptSubmit`. Повтори `node install.js`.
- **«claude not found».** Задай `CLAUDE_BIN` полным путём до `claude` (на Windows это `claude.exe`, не `claude.cmd`: рерайтеру нужен запуск без оболочки).
- **Рерайт не получился.** Claude выполнит исходную задачу как написана и одной строкой скажет, что рерайт пропущен.
- **Долго.** 10-30 секунд это нормально: идёт отдельный запрос. Для скорости поставь `OPT_MODEL=haiku`.

## Ограничения

- Хук не умеет заменить текст твоего сообщения, поэтому результат рерайта идёт как дополнительный контекст, а оригинал тоже виден модели.
- Проверено на Windows 11. Поиск `claude` на macOS и Linux написан, но на этих системах пока не запускался; если что-то не так, напиши в Issues.
